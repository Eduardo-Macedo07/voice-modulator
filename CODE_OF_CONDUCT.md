# Code of Conduct

## Our pledge

We want Voice Modulator to be a welcoming project for everyone who uses it or contributes to it, regardless of age, background, identity, experience level or nationality.

## Expected behavior

- Be respectful and constructive in issues, pull requests and discussions.
- Accept feedback gracefully and give it kindly.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, insults, discrimination or personal attacks.
- Publishing other people's private information.
- Using the project to build or distribute malware, or to deceive or harm others (for example, voice impersonation used for fraud or harassment).
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

The maintainer may edit or remove comments, close issues and pull requests, and block contributors who violate this code of conduct.

To report a problem, open an issue at https://github.com/Eduardo-Macedo07/voice-modulator/issues or contact the maintainer through their GitHub profile, [@Eduardo-Macedo07](https://github.com/Eduardo-Macedo07).

## Scope

This code of conduct applies to all project spaces: the repository, its issues and pull requests, and its releases.
